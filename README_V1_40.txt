PROYECTO ARANZA v1.40

Esta versión agrega contexto histórico a la revisión de posibles duplicados o contradicciones de memoria.

Cuando una propuesta se parece mucho a otra que ya fue revisada para el mismo recuerdo y la misma cuenta, Aranza muestra la decisión previa y una nota aclarando que no es un veredicto automático. La coincidencia se calcula con palabras compartidas; no es comprensión semántica.

No se ocultan candidatos, no se cambian recuerdos automáticamente y las decisiones de otras cuentas no se muestran.

Validación local de esta versión:
- Compilación Python y suite de pruebas: ver resultado informado junto con el archivo ZIP.
- No implica despliegue, prueba en navegador real ni validación con un proveedor de IA conectado.

Incluye CHANGELOG_V1_40.md y test_memory_review_context.py.
