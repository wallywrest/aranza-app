PROYECTO ARANZA v1.26

Novedad principal: vista previa de memoria disponible desde el panel «Memoria de Aranza» en la interfaz web.

Uso:
1. Ejecuta el backend de Aranza e inicia sesión normalmente.
2. Abre «Memoria de Aranza».
3. En «Probar qué recuerda Aranza», escribe una consulta.
4. Pulsa «Previsualizar contexto» para ver los recuerdos que la API seleccionaría.

La vista previa no modifica los recuerdos. La selección sigue siendo léxica, no una comprensión semántica completa.

Esta versión no ha sido desplegada ni probada con proveedores reales. Conserva una copia de seguridad de tus archivos antes de integrar cambios en tu instalación.
