Proyecto Aranza v1.43

Novedad: endpoint de solo lectura GET /memory/timeline.
Reúne recuerdos actuales y versiones anteriores preservadas al editar o restaurar, en orden cronológico inverso. Solo incluye datos de la cuenta autenticada. El límite se restringe a 1–200 eventos.

La línea temporal refleja únicamente los eventos que la aplicación registra. No reconstruye conversaciones completas ni demuestra por sí sola cuándo cambió una preferencia en la vida real.

Para instalar, integra este parche con la versión base consolidada siguiendo el README principal. Esta entrega no está desplegada en producción.
