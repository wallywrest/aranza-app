PROYECTO ARANZA v1.34
Memoria activa y archivada

NOVEDADES
- Puedes archivar recuerdos que ya no quieres que Aranza use como contexto automático.
- Archivar no borra el recuerdo: permanece en tu lista y puedes reactivarlo.
- El estado se muestra en la lista de memoria.
- La API valida autenticación y cuenta propietaria.
- La base de datos existente se actualiza con una migración aditiva al inicializarse.

USO
1. Extrae el ZIP en una carpeta de trabajo.
2. Conserva tu archivo de configuración y tu base de datos existentes; no los reemplaces con archivos de ejemplo.
3. Sigue README_CONFIGURACION.txt para preparar el entorno.
4. Inicia el servidor y entra a Memoria de Aranza.
5. Usa Archivar para excluir un recuerdo del contexto; usa Reactivar para volver a permitir su selección.

IMPORTANTE
Esta versión conserva los recuerdos archivados, pero no incluye borrado definitivo de versiones del historial. Haz una copia de seguridad de la base de datos antes de actualizar. La validación automatizada local pasó 91 pruebas. No se ha desplegado ni probado con un proveedor de IA externo en una sesión de navegador real.
