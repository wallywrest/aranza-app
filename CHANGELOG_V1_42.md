# Proyecto Aranza v1.42

## Memoria con señales temporales explícitas
- La revisión de recuerdos identifica marcadores textuales como «antes», «ahora», «actualmente», «ya no», «dejé de» y «desde hace».
- Las señales se muestran por separado para la propuesta nueva y el recuerdo existente.
- La detección es heurística: no decide si hay contradicción, no cambia recuerdos y no reemplaza la revisión humana.
- Se mantiene el aislamiento de memoria por cuenta y el contexto de revisiones anteriores.

## Validación
- Añadidas pruebas para marcadores temporales, ausencia de marcadores genéricos y ausencia de modificaciones automáticas.
