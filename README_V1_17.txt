ARANZA v1.17 - INTEGRACIÓN DE BÚSQUEDA WEB

Esta versión añade el botón 🌐 en el chat. Actívalo para que la siguiente consulta busque fuentes públicas y entregue los títulos, URLs y fragmentos al modelo. Desactívalo para volver al chat normal. La búsqueda viene desactivada por defecto.

IMPORTANTE:
- Los fragmentos del buscador no equivalen a verificar el contenido completo de una página.
- Revisa las URLs antes de confiar en una respuesta.
- Mantén tu base de datos y archivo .env fuera del ZIP al actualizar.
- No está desplegada en tu servidor; valida primero con una copia del entorno.
