PROYECTO ARANZA v1.20

Esta versión conecta la búsqueda web del chat con el lector de páginas públicas.

Al activar el botón 🌐, Aranza busca fuentes y trata de leer hasta dos páginas. Si una página no se puede leer, continúa usando los fragmentos disponibles. El texto leído se limita antes de enviarse al modelo y se marca como contenido externo no confiable.

Instalación: por ahora conserva este ZIP como versión de desarrollo. No reemplaces todavía tu instalación ni tu base de datos. Antes de una instalación final habrá que integrar y probar todos los cambios, respaldar SQLite y revisar las variables de entorno del hosting.

Validación local: 60 pruebas aprobadas. Las pruebas son automatizadas y no confirman el funcionamiento de proveedores reales ni el despliegue.
