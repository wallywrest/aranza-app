Proyecto Aranza v1.30

Esta versión conecta el detector de recuerdos similares con el formulario de creación. Si hay candidatos, se muestran en pantalla y se pide confirmación antes de guardar. El usuario conserva la decisión; no hay fusiones ni borrados automáticos.

La similitud es léxica aproximada. La versión no ha sido desplegada ni probada con un proveedor real de IA.

Consulta README_CONFIGURACION.txt para los pasos de configuración generales.
